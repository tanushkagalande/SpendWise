# SpendWise – Personal Expense Tracker

SpendWise is a personal expense tracking web application built with React. It helps users manage income, expenses, monthly budgets, and savings goals through an interactive dashboard.

## Features

- Add, edit, and delete transactions
- Track income, expenses, and total balance
- Categorize transactions
- Monthly budget tracking
- Interactive pie and bar charts
- Savings goals with progress tracking
- Search, filter, and sort transactions
- Export transactions to CSV
- Dark mode
- Data persistence using browser LocalStorage

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Recharts
- Vite
- LocalStorage

## Installation and Setup

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd spendwise
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

## Data Storage

The application currently uses browser LocalStorage to save transactions, budgets, and savings goals.
